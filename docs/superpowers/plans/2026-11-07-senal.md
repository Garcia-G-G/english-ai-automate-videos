# Señal Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A text-free 3D page that shows every recent video as a ridge, auto-flies to the one beating its format's typical curve, and shows why with light and particles.

**Architecture:** A Python engine (`src/senal.py`) reads YouTube Analytics, scores each video against its format's typical curve and writes `output/senal/senal.json`. A Vite + TypeScript + three.js app (`senal/`) renders it. A tiny stdlib server (`src/senal_server.py`) serves the built app and the JSON on 127.0.0.1, started from the Streamlit panel.

**Tech Stack:** Python 3.12 + pytest; Node 26, Vite, TypeScript, three, postprocessing (pmndrs), gsap, vitest, @fontsource-variable/inter.

**Spec:** `docs/superpowers/specs/2026-11-07-senal-design.md` (approved 2026-11-07). Read it before any task; section numbers below (§N) refer to it.

## Global Constraints

- No paid API. Only YouTube Data API v3 and YouTube Analytics v2 with the channel token (`channel_stats._youtube_token()`).
- No text in the scene at rest (§2). Only exceptions: numbers mode while held/toggled (§7) and the error message (§8).
- Data hues: Shorts feed `#3987e5`, search `#199e70`, external `#d95926`; background `#05070f`; lines `#dfe6ff`. Shares gold, subs white (§5).
- Horizontal axis always days 0–14; `daily` has at most 15 values (§4, §5).
- Thresholds live in module constants: `BREAKOUT_SCORE = 2.0`, `BREAKOUT_MIN_VIEWS = 300`, `COLD_SCORE = 0.5`, `WHY_RATIO = 1.5`, `DAYS = 14`, `COHORT_DAYS = 90`, `MIN_COHORT = 8`, `SECOND_WIND_MIN = 20` (my call: a day-3+ rise under 20 views is noise).
- State precedence: `breakout` > `second_wind` > `cold` > `normal` (§6).
- Hover and click use the same pick function (§7). A user drag cancels any camera tween (§7).
- `prefers-reduced-motion` skips the opening and all tweens; the render loop pauses on `visibilitychange` hidden (§7, §9).
- Zero console errors; zero network requests besides `senal.json` and bundled fonts (§9).
- Tests never touch real `output/`, `content/` or logs: `senal.SENAL_DIR` and `channel_stats.STATS_DIR` are redirected in `tests/conftest.py`.
- Before writing code against three, postprocessing, gsap or vite, check their current docs with context7 (owner's global rule).
- Code, comments, commits in English; no keys, `.env`, voice IDs or home paths in commits; no attribution lines; commit locally, never push.
- Do not edit the tree while a render job is running in the panel.

## Review Focus

1. A video published today or yesterday (`daily` of length 1–2, cumulative typical 0) must score `None`, state `normal`, and draw a short ridge, never crash or flag as breakout. → test in Task 1.
2. A video with zero views or no Analytics rows must not divide by zero in the per-1k factors and gets `why == []`. → test in Task 1.
3. An expired/missing YouTube token during refresh must keep the previous `senal.json` untouched and surface the error text in the panel; the page then shows the stale state. → test in Task 2.
4. The local server must never serve anything outside `senal/dist` and the one JSON (`/../.env`, `/%2e%2e/.env`, absolute paths → 404). → test in Task 7.
5. A malformed or version-mismatched `senal.json` must render the §8 error state, not a blank canvas. → test in Task 3.

  - `score(daily: list[int], cum_typical: list[float]) -> float | None` — cumulative views at the video's age ÷ `cum_typical[age]`; `None` when that typical value is 0.

  - `why(video: dict, medians: dict, channel_sources: dict) -> list[str]` — subset of `["search", "external", "retention", "shares", "subs"]`, ordered by ratio desc, each > `WHY_RATIO`. `video` has `views, retention, shares, subs, sources`; `medians` has `retention, shares_per_1k, subs_per_1k`.
