# ADR 0010: Panel 2.0, a local web app over the Python engine

Status: accepted (Garcia, 2026-11). STEP 85 builds the foundation; STEPs 86-88 finish it.

## Why we leave Streamlit
Streamlit re-runs the whole script on every click. Even with caching, a click costs 0.15-0.5 s on warm pages and
1.7 s cold on Inicio, and there is no way to animate, keep state between views or stream a job's steps without
re-running the page. The «Mezcla» design (springs, count-ups, live job steps, confetti) needs a client that
keeps its own state and receives events.

## Shape
- `src/panel_core/`: the engine facade. No UI. Queue reading, the video lists, approve/reject, next best, slots,
  costs, gate records, job state. `admin.py` (Streamlit) and the API both import it; `import panel_core` never
  imports streamlit (a test pins it).
- `src/panel_api/`: FastAPI + uvicorn on 127.0.0.1:8600. Thin JSON wrappers over panel_core, plus
  Server-Sent Events for job steps. It serves the built app (`panel/dist`).
- `panel/`: Vite + React + TypeScript. It displays and calls; no rule is duplicated in TypeScript (priority,
  slots, the repetition guard, costs and gates stay in Python). API types are generated from the OpenAPI schema.

### What panel_core holds (STEP 85 §1)
One small module per concern, all UI-free, each a facade over the existing rule (no rule is copied):
`videos` (lists, sidecar, approve/reject files), `queue_read` (queue order, next best, refused scripts),
`schedule` (`schedule_info` builds the front end's `ScheduleInfo`, plus `slots.check_time`/`explicit`),
`costs` (costs snapshot, gate record, voice-lock state, read only), `review` (approve with or without a time,
reject with a reason, re-render), `jobstate` (jobs with per-step progress, progress listeners) and `thumbnails`
(the STEP 85b paths). Job steps (guion, voz, sonido, montaje, control, each 0..1) are bands of the pipeline's one
`progress` number, written by `jobs.update_job`; Streamlit still reads `progress` and shows the same thing.
The guarded upload behind «Aprobar y programar» (guard, attempt log, ledger, Meta lock) moved to `panel_core/upload.py`
(STEP 85 §4); admin.py keeps thin wrappers, and `jobs.prepare_generation` is the one job-start path for Streamlit and the API.

## Paid actions stay locked
Nothing changes in the locks: `ELEVENLABS_LOCK`, the OpenRouter caps ($0.25 per Short, $15 per month) and the
STEP 79 §00 grant. The Streamlit «panel click» permission is replaced by a spend gate: a random per-session token
served only inside the HTML the server serves, required in a header on every paid route together with
`"confirm": true`, with Origin and Host pinned to 127.0.0.1:8600 / localhost:8600. The lock opens only inside such a
request. The CLI, pytest and tools stay locked.

### Threat model of the spend gate (STEP 85 §3, STRIDE, short)
1. **Spoofing / CSRF:** another web page in Garcia's browser POSTs to 127.0.0.1:8600. Mitigated: paid routes need
   `X-EU-Session` (a custom header a cross-site form cannot send, and a cross-origin fetch needs a CORS preflight we never
   answer), plus Origin and Host pinned to the panel; a POST with no Origin is refused.
2. **DNS rebinding:** a hostile name resolves to 127.0.0.1. Mitigated: the Host header must be `127.0.0.1:8600` or
   `localhost:8600`; the server binds 127.0.0.1 only. The Vite dev origins (5173) are allowed only with `EU_PANEL_DEV=1`.
3. **Information disclosure of the token:** it lives in memory (`secrets.token_urlsafe(32)`, one per process) and is
   served only as the `eu-session` meta of `index.html` (`no-store`). It is never logged, never in a JSON body or an
   error; a test scans every response and header. Residual risk: a same-origin script or a local process that fetches `/`
   can read it; that is the accepted boundary of a single-user local app.
4. **Elevation / unplanned spend:** the voice lock opens only inside `gate.run_job`, which a paid handler calls after the
   gate; the grant is held by the job's thread and closed when it ends, even on error. The CLI, pytest and tools never
   call it, so they stay locked; `ELEVENLABS_LOCK` still beats everything. `confirm: true` is a literal boolean.
5. **Repudiation / DoS:** every paid job already writes the cost ledger and the job row; the token compare is constant-time
   (`secrets.compare_digest`). No rate limit beyond the existing caps ($0.25 per Short, $15 per month, STEP 79 §00); a
   double click is stopped by `AlreadyRendering`.

## Switch-over
1. STEP 85: foundation, design system, Inicio, producing a video end to end. Streamlit untouched on 8501.
2. STEPs 86-87: Revisar, Crear, Cola, Rendimiento, Biblioteca, Comentarios in the new app.
3. STEP 88: the new panel becomes the default, Streamlit is retired, the engine gets its performance pass.
Until then both panels run side by side and read the same files.

## Consequences
- Two front ends exist for a while; every rule lives in panel_core so they cannot disagree.
- A new toolchain (node, pinned exact versions, bundled fonts, no runtime network).
